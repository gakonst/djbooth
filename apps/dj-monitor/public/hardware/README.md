# Hardware reference assets

Local reference photography used by the hardware-state visualization. The app has no runtime CDN
dependency.

- `CDJ-3000_top.webp`: official Pioneer DJ CDJ-3000 top view, downloaded from the
  [CDJ-3000 product page](https://www.pioneerdj.com/en/product/dj-players-turntables/cdj-3000/).
- `djm-a9_2.png`: official Pioneer DJ DJM-A9 front/top view, downloaded from the
  [DJM-A9 product page](https://www.pioneerdj.com/en/product/dj-mixers/djm-a9/).

Pioneer DJ product names, logos, and product photography belong to their respective owner. Keep
these assets scoped to the local visualization/reference implementation.
