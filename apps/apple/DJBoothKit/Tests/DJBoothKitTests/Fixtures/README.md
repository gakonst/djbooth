# USB reader fixture

`usb-export.pdb` is synthetic data generated by the repository's
`LegacyDevicePdbWriter` in `packages/rekordbox-ts/src/devicelib/pdb.ts`, using its
embedded empty Rekordbox Device Library template. No personal library data is included.

It contains 40 tracks (IDs 1–40), crossing several data pages. Track 1 is named
`Νύχτα 🌙` and has a 140-character ASCII comment; other titles are `Track N`.
All tracks have Artist / Album / House / Am, 128.50 BPM, 321 seconds, and paths
`/Contents/Artist/Track N.mp3`.

Playlists are `Weekend` (folder 1), `Warmup` (folder 2 under 1), `Opening`
(playlist 3 under 2), and `Empty` (playlist 4 at root). Opening's entries were
written in order `(position 3, track 2)`, `(position 1, track 1)`,
`(position 2, track 2)` to exercise sorting and repeated membership.

`HISTORY 001` contains tracks `[2, 1, 2]`, appended with the same writer to exercise
CDJ history reading and repeated plays before CLI sync imports them.
