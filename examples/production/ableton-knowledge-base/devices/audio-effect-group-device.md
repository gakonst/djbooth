# AudioEffectGroupDevice

Represent Ableton's serial, parallel, layered, return, selector, and macro graph structure.

## Production use

Use chains to split dry/wet or frequency roles, selectors for variations, and macros for musically meaningful multi-parameter control.

- Kind: rack-and-routing
- Domains: routing, layering, macros
- Headless status: partial
- Engine status: exhaustiveParseProven
- Preset status: valuesMappingsAndZonesRecovered
- Mechanism: rackGraph
- Safe claim: Rack structure can be parsed; complete native graph execution is not yet proven.
- Remaining blocker: native execution of parallel chains, sends, selectors, and nested mixer routing is not complete
- Custom DSP: false
