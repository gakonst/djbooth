# Roar

A multi-stage distortion and feedback sound-design system with routing, modulation, filtering, compression, and time behavior.

## Production use

Choose serial, parallel, or multiband routing intentionally; drive only the region needing density, use modulation for life, and control output after nonlinear stages.
