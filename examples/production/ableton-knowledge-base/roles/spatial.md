# Depth and spatial effects

Build a coherent front-to-back and side-to-side scene using filtered shared spaces, selective delays, and dynamic clearance.

## Build order

1. Declare foreground and background roles.
2. Create a small number of shared spaces.
3. Filter returns and set predelay/decay from density.
4. Use delays to occupy rhythmic gaps.
5. Duck or automate wet paths when foreground clarity is needed.

## Listen for

- Foreground remains intelligible
- Returns share a believable character
- Low end stays dry and stable
- Tails change with arrangement density
