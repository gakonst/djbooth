# Snare and clap

Separate attack, body, noise, width, and room so the backbeat is deep without becoming washy.

## Build order

1. Pick a body with the right pitch and decay.
2. Add a short noise/transient layer only if needed.
3. Shape harshness before adding air.
4. Use a short room or controlled send for depth.
5. Vary support hits while keeping the primary backbeat stable.

## Listen for

- Body at mix level
- No brittle top
- Room ends before the next important event
- Centered impact with optional wide tail
