# Evidence-to-track workflow

1. Query by intended lane, role, energy, and sonic problem; retrieve compatible track, producer, and tutorial documents.
2. Select a three-to-five track reference panel: groove, bass articulation, hook grammar, arrangement contrast, and spatial/mix depth can come from different references.
3. Build MIDI grammar from measured onset slots, note lengths, interval tendencies, phrase lengths, and stem-entry maps. Do not trace one copyrighted melody.
4. Orchestrate only through real Ableton assets/devices and hosted plugins whose headless path is proven. Use real racks, presets, grooves, samples, sends, and automation.
5. Require evolving parts: motif variation, counterline, percussion answers, fills, ear candy, filtered or resampled variants, and section-specific effect states.
6. Render and extract the same profile used for references. Compare section contrast, stem ratios, syncopation, spectrum, transient density, width, and MIDI density.
7. Revise the largest audible deltas, then audition the whole arrangement and focused payoff/breakdown excerpts.

Current evidence: 47 analyzed tracks and 1432 tutorial windows.
